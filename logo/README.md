# Vandor Labs — selected square-core logo

Flat artwork for the selected middle logo. The only wordmark is VANDOR LABS.

- `vandor-labs-light-background.svg/png`: dark wordmark for light surfaces.
- `vandor-labs-dark-background.svg/png`: light wordmark for dark surfaces.
- `vandor-labs-icon.svg/png`: standalone pictogram.

Wordmark PNGs are 1440×480; icon PNG is 1024×1024. All have transparent backgrounds. SVGs contain only rectangles: lettering and pictogram are fully outlined, with no font dependency. Cyan #72DCE5; dark ink #13212B.

The selected concept has been redrawn on a strict grid for consistent blocky edges. These are static flat graphics without glow effects. Minecraft on/off textures are supplied separately.
