# Programmable Screen copied settings

`exportCopifierScreenSourceReference` freezes 5,866 actual released `ProgrammableSettings.capture/apply` observations for all seven Screen roles: 896 full copies across metadata/factory/saved profiles, 4,872 partial edits and 98 row-configuration cases. The expanded `testclient/fixtures/copifier-screen-source.jsonl.gz` is 31,388,880 bytes, SHA-256 `47cb5d0364cfe991f3fdc9f156552fe1a271d991e8a80b30f09d5c37c086859f`.

The copier calls the raw Screen setters rather than the dedicated editor transaction. Activation is a wrapped `DisplayActivation` compound, applied before the legacy trigger setter. Surface changes can enable/disable row headers before copied row configuration. Explicit surface layout takes precedence over the old tile flag. Raw secondary/small settings remain stored even when dormant on a particular role. Frame artwork version is forced to one on the Source display-artwork roles. Copied row configuration validates both headers, truncates to each role's four/eight row capacity and preserves target bank state by index while resetting the copied pulse configuration. Invalid row configuration can be ignored while earlier valid scalar edits remain applicable.

Direct CHIP selection does not use the editor's reader-availability check. Embedded physical chips and runtime journal pages remain local; the oracle checks their unchanged reader payload and page field after every callback, and the clipboard excludes both. Saved page presence still follows the released selected-surface writer. Vehicle surfaces, carried controls and propulsion simulation are excluded.

These are actual callbacks in a fixed-clock memory world. They establish setter order and serialization policy, not native commit, player/packet authorization or restart. Deferred and channel state is retired through actual unload callbacks. Public Copifier dispatch remains unchanged.

`testCopifierScreenReference` matches all 5,866 independent native plans against Source initial/final captures and typed applicability. The plan keeps scalar-stage and final-stage settings separate to preserve ordering, and represents row choices without pulse deadlines or latch maps. It reuses the existing Screen, activation, frame, channel and row codecs while permitting Source's dormant raw fields. Vehicle selection is explicitly refused. Caller compounds remain unchanged, and physical chips/pages never enter the value. Installed publication and row-bank/runtime parity remain separate acceptance requirements.

Installed Screen copying uses a typed settings snapshot rather than whole-tile serialization. `NativeScreenEntity.configureCopied` preflights the entire value, stages Source's scalar setters, row-header transitions, copied row options and metadata tail inside the existing channel batch, then publishes the final immutable projection. Row-service staging retains the destination latch banks by index; no physical-reader load, insertion callback or journal materialization occurs. An explicit copied activation is saved independently of untouched retained activation bytes.

The canonical dedicated `test_copifier_screen.py` replay checks all 5,866 Source callbacks, including normalized saved row feedback, latch levels and pulse deadlines, caller and installed-owner identity, unchanged embedded chip envelopes and journal pages, and public-update privacy. Separate copied owners of all seven roles survive a complete process restart, including one usable embedded chip per owner and unrelated opaque saved fields. Invalid whole-value and worker edits refuse before mutation. This exercises the typed host hook; common Copifier target dispatch, claims and real player packets remain a separate integration step.

The existing `test_screen_host.py` regression also passes after the row-service extraction: 327 write checks and 25 restart checks, including row actions, deferred registration, remaining pulse expiry, independent toggle ownership and idle queues. Both focused suites finalize retention only after their restart process exits. No renderer or global Copifier dispatch changes are included.
