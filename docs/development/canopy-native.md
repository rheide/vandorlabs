# Standalone canopy conversion boundary

The canopy foundation is inactive. Its immutable settings retain the distinct canopy defaults and typed-tag rules, including absent depth 16, scale 71, hinge 2, angle 1 and enabled power polarity. Saved layout 2 overrides the legacy tile-material flag; other layouts retain that flag's precedence. Unknown material integers remain intact. This policy is separate from ordinary programmable glass and diagonal panel glass.

Initial placement scalars preserve the specialized canopy item's facing, mount and anchor arithmetic. The centered two-wide visor reserves three cells when newly placed. Variable front-canopy anchors and fixed footprints match the released item callbacks; variable shell eligibility, existing-canopy hit adjustment, pairing, released helpers and lifecycle recovery remain separate work. Older missing centered/hollow placement flags must retain their original semantics when the host is implemented.

Joined opening canopies distinguish rendering ownership from item ownership. Up to nine compatible columns share one renderer, while each constituent column retains its own configured drop. Source callback records cover forward/reversed placement, gaps, blocked members, the nine-column limit and post-AIR mining of anchors or helpers. Appearance differences do not prevent joining; mount, motion and angle do, while travel direction matters only in sliding mode. Harvesting first unpairs the group and then uses the mined constituent's own settings. Native pairing and ownership installation remain pending.

Physical geometry remains separate from render clearances and UV subdivision. Variable front shells use the released glazing and two-pixel rail collision approximation; other canopies retain ordered dyadic triangle boxes. The shared scalar kernel matches 1,191,320 actual Source boxes, selection bounds and 5,104 exact surface rays across 176 profiles. It preserves the extra zero-angle hinge arithmetic in the released collision path, strict nearest-triangle ties, on-surface starts and near-parallel rejection. This proves the geometry kernel; loaded-world targeting and collision routing are not activated by it.

Canopy points and rigid transforms preserve the released float-sqrt normalization and Java 8 degrees-to-radians operation order. Pose comparisons cover every mount and hinge, both motion modes and travel directions, widths 1, 3 and 9, and inverted polygon winding.

The shared drawing foundation contains immutable world-free polygons, surface subtraction, panel UV tiling and rigid-part visibility. Each preparation cache binds one immutable kind, width and settings value; it contains no tile or world references. The final emitter is independent of the destination vertex format. Moving-shell emission retains the released triangle-back ordering and truncated alpha conversion. Fixed chunk quads retain their different triangle-back ordering and rounded alpha conversion.

The released `regular_canopy_glass` uses a chunk model; the other ten standalone kinds use the canopy block-entity renderer. Independent actual Source corpora establish both paths: 1,320 shell profiles contain 2,503,200 final vertices, while 1,944 fixed-glass profiles contain 429,840 quads across all valid connection/roof masks. Native authored base generation first matches 552 separately frozen Source bases, including deformed fronts, generated opening shells, visor rails and roof joins. The complete native authored-base, shared-geometry and emission pipeline then matches the independent final records. Seven original artwork sheets are mirrored unchanged; the inactive atlas/material adapter now has a private native title check covering all eleven families, original sheets, opacity, mounts, motion samples and reload. Its warmed twelve-snapshot actual vertex-consumer batch submits 279,180 vertices with zero measured heap allocation and no new meshes. The combined mesh/identity cache is bounded to 8 MiB and retired on resource publication or client world unload. This is software-rendered, stationary-path evidence; moving-path costs, concrete host lifecycle, editor, items and placed-world acceptance remain pending. No public registry or bootstrap activation is supplied by this foundation.
