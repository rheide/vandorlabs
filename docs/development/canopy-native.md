# Standalone canopy conversion boundary

The canopy foundation is inactive. Its immutable settings retain the distinct canopy defaults and typed-tag rules, including absent depth 16, scale 71, hinge 2, angle 1 and enabled power polarity. Saved layout 2 overrides the legacy tile-material flag; other layouts retain that flag's precedence. Unknown material integers remain intact. This policy is separate from ordinary programmable glass and diagonal panel glass.

Initial placement scalars preserve the specialized canopy item's facing, mount and anchor arithmetic. The centered two-wide visor reserves three cells when newly placed. Variable front-canopy anchors and fixed footprints match the released item callbacks; variable shell eligibility, existing-canopy hit adjustment, pairing, released helpers and lifecycle recovery remain separate work. Older missing centered/hollow placement flags must retain their original semantics when the host is implemented.

Canopy points and rigid transforms preserve the released float-sqrt normalization and Java 8 degrees-to-radians operation order. Pose comparisons cover every mount and hinge, both motion modes and travel directions, widths 1, 3 and 9, and inverted polygon winding.

The shared drawing foundation contains immutable world-free polygons, surface subtraction, panel UV tiling and rigid-part visibility. Each preparation cache binds one immutable kind, width and settings value; it contains no tile or world references. The final emitter is independent of the destination vertex format. Moving-shell emission retains the released triangle-back ordering and truncated alpha conversion. Fixed chunk quads retain their different triangle-back ordering and rounded alpha conversion.

The released `regular_canopy_glass` uses a chunk model; the other ten standalone kinds use the canopy block-entity renderer. Independent actual Source corpora establish both paths: 1,320 shell profiles contain 2,503,200 final vertices, while 1,944 fixed-glass profiles contain 429,840 quads across all valid connection/roof masks. Native shared geometry and emission match those records using separately frozen Source-prepared base polygons. Authored base generation, native atlas/material integration, concrete host lifecycle and actual native GPU acceptance remain pending. No public registry or bootstrap activation is supplied by this foundation.
