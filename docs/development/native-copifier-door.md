# Door copied settings

The ordinary Door reference invokes the released `ProgrammableSettings.capture` and `apply` callbacks for `programmable_door` and its two retained motion aliases. It freezes 144 captures and 240 full/partial applications, including upper-cell resolution to the lower owner. The expanded SHA-256 is `fd5ddea41ed7d2dfed3bd042a3b1f6df917367447620c531fef38cfcf6e1ec07`; the compressed corpus is `testclient/fixtures/copifier-door-source.json.gz`.

Cases cover glazing, effective layout and its legacy flag, face artwork, security, panel/depth and motion choices, channels, frame metadata, invalid values and the global preflight. Independent undo observations preserve the actual setter order. This is a callback reference using a simulated world; it does not establish native world behavior, reader-inventory ownership or player-packet acceptance. Large and Segmented Doors and Trapdoors remain separate copied-target work.
