# Door copied settings

The ordinary Door reference invokes the released `ProgrammableSettings.capture` and `apply` callbacks for `programmable_door` and its two retained motion aliases. It freezes 144 captures and 240 full/partial applications, including upper-cell resolution to the lower owner. The expanded SHA-256 is `fd5ddea41ed7d2dfed3bd042a3b1f6df917367447620c531fef38cfcf6e1ec07`; the compressed corpus is `testclient/fixtures/copifier-door-source.json.gz`.

Cases cover glazing, effective layout and its legacy flag, face artwork, security, panel/depth and motion choices, channels, frame metadata, invalid values and the global preflight. Independent undo observations preserve the actual setter order. This is a callback reference using a simulated world; it does not establish native world behavior, reader-inventory ownership or player-packet acceptance. Trapdoors remain separate copied-target work.


The native pure plan matches every frozen callback and its installed ordinary target passes the same captured settings/application results through the common tool service. Upper cells resolve to the logical lower owner with independent permission checks; physical connected traversal deduplicates logical owners. A typed selected-leaf commit leaves private reader items, opaque retained fields and physical ownership installed. Dedicated checks include previous-release credential payloads, protected/stale/worker/recovery refusals, undo and process restart (1,651 write/three read assertions). The real client passes upper capture/application, Connected and Undo through actual widgets and packets. Existing single-cell connected checks pass after logical-owner generalization. The tool remains privately registered; Large and Segmented Doors and Trapdoors are not covered by this ordinary adapter.


### Large Door copied targets

Any of the nine cells resolves to the same anchor, with clicked-cell and anchor permissions checked independently. Capture and typed commits preserve all nine physical owners, contained credentials, unrelated data and placement facing. Connected copying deduplicates anchors, and Undo uses the common settings-only history. The Large-specific design limits and unversioned rotating-model migration are preserved.
