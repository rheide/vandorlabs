# Segmented Door render caches

Closed, eligible opaque panels already publish immutable terrain models to the chunk renderer, with a render-upload acknowledgement before suppressing the matching tile-render fallback. Moving columns, windows, layered glazing and authored gate models need their dynamic paths. Keep their immutable artwork separate from pose, world translation and lighting; making every design a chunk model would require handling those state changes and transparent layers explicitly.

Forge's moving-column cache now shares immutable configuration descriptors between equivalent columns. A renderer-local scratch descriptor performs lookup without allocating row arrays or retaining a mutable key. A retained template owns its copied descriptor, and columns reference that same immutable value. Exact equality still covers per-row artwork, window layouts, settings, pose frame, facing and dimensions. Vertex formats, atlas reload, world unload, changed artwork and lighting retain their existing invalidation paths. The 2 MiB template and 16 MiB column limits now conservatively charge descriptor retention as well as vertex data.

A focused actual-renderer density fixture submits 512 equivalent three-section window columns through eight changing poses. The original negative retained 512 descriptors and allocated 945,528 bytes over the last four frames. The corrected fixture retains one shared descriptor and allocates 462,056 bytes for the same 835,584 emitted vertices, a 51% reduction in measured allocation. Retention is 6,669,776 bytes including the newly charged descriptors. This is CPU emission and retained-memory evidence, not hardware FPS or a claim that every moving column is allocation-free.

The exact standard JAR also passes 11,520 cached/reference vertex comparisons with vanilla and extended formats, 96 actual per-cell artwork invalidations, 84 swept-bound observations, 36 cache/light cases, custom and edge UV checks, pause/reversal/ordering contracts and the rendered padded icon. Its SHA-256 is `6b8d1831d550683fe8e9c15afb3514f62f76703fb8bda14a1b60fb65c7abaed0`. The full release gate remains deferred.

Supplied gate rows use generation-bound authored meshes and prepared neighbour contexts rather than rebuilding bars or rediscovering topology each frame. Their separate Source player/reload check observes no topology reads in 10,000 warmed accesses. Native complete row emission additionally passes 10,000 warmed calls with zero allocation in both atlas generations. See [supplied gates](segmented-supplied-gates.md) for actual joined motion and layered-artwork coverage. These measurements do not replace a full dense native-world profile.
