# Native Ramp editor contract

The editor keeps the scan face separate from horizontal travel. The full controller and slab use their actual scan direction; selecting the Y layout remains restricted to side mounts. The existing seven mode indices remain ramp, filled ramp, lift, extend, escalator up, escalator down and moat. Reverse clicks select the previous mode. Entering an escalator resets the start offset and travel axis; moat resets the travel axis. Live analog deployment remains a separate Redstone choice and is deliberately absent from configured-item and Copifier captures, matching the released paths.

Refused configurations apply neither. This establishes command ordering, not durable actor receipts, asynchronous journals, platform ownership or live motion.
