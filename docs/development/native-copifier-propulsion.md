This scope covers placed engine and hover fixtures only. Vehicle preview, propulsion simulation and carried controls are excluded. `exportCopifierPropulsionSourceReference` invokes the actual released `ProgrammableSettings.capture/apply` callbacks for all 27 registered fixture blocks: 1,728 full-copy cases covering metadata/factory/saved profiles and 6,966 partial edits. The copier changes shape first, then applies settings to the resulting block. An unchanged shape is a settings operation. The selected family's identity and facing remain local, and shape changes retain the same physical tile. Join applies only when the resulting block supports it. Manual/particle edits temporarily clear the channel restriction, preserve the received channel selection, and distinguish byte particle toggles from integer levels. Missing nested signal fields reset to their getter defaults. Hover fixtures ignore the engine-only shape key. Generic copied frame/transmission compounds are not supported by this Source tile, although their global validation can still refuse malformed input.

The oracle uses actual Source callbacks in a memory world, including local initial-state capture; it proves callback policy and retained tile identity rather than networking, player authorization or native restart behavior.
