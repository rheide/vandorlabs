# Programmable Rocket Thruster

The Rocket Thruster provides the rocket-family emitter texture, light, and particle stream. Choose its shape in the settings dialog after placing it; the facing comes from placement and a wedge uses the clicked corner.

| Shape | Close-up |
| --- | --- |
| Block | ![Rocket block](../images/gallery/propulsion/rocket-thruster-block.png) |
| Hexagon | ![Rocket hexagon](../images/gallery/propulsion/rocket-thruster-hexagon.png) |
| Wedge | ![Rocket wedge](../images/gallery/propulsion/rocket-thruster-wedge.png) |

Normal right-click cycles its manual state through Off, On, and On + Particle Stream. Shift-right-click in Creative mode configures Shape, Join, redstone behavior, and channel. See [propulsion settings and connected blocks](propulsion.md).
