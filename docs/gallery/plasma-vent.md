# Programmable Plasma Vent

The Plasma Vent provides the plasma-family emitter texture, light, and particle stream. Choose its shape in the settings dialog after placing it; the facing comes from placement and a wedge uses the clicked corner.

| Shape | Close-up |
| --- | --- |
| Block | ![Plasma block](../images/gallery/propulsion/plasma-vent-block.png) |
| Hexagon | ![Plasma hexagon](../images/gallery/propulsion/plasma-vent-hexagon.png) |
| Wedge | ![Plasma wedge](../images/gallery/propulsion/plasma-vent-wedge.png) |

Normal right-click cycles its manual state through Off, On, and On + Particle Stream. Shift-right-click in Creative mode configures Shape, Join, redstone behavior, and channel. See [propulsion settings and connected blocks](propulsion.md).
