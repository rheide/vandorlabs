# Vanilla vehicle block weights

Vanilla Minecraft **1.12.2**. Current estimate rules: **version 1**. One full stone block is **1 weight unit**. Values are game estimates per occupied block cell, including each half of a multi-block structure separately. They are not kilograms and do not affect movement yet.

The table is generated from the implemented estimator. The default-state weight is shown first; variants with a different estimate are listed separately. Facing, colour, opening and other states are omitted when they do not change weight. Values are rounded to eight decimal places. Registry entries include technical and unassemblable blocks: this is a weight reference, not a list of supported vehicle blocks.

Full-block examples: wood 0.25, ordinary stone/glass 1, iron 3 and gold 7.5. Slabs normally use half the material weight; stairs use three quarters. Other recognised thin shapes have smaller factors. Blocks without a recognised material or shape use the material fallback and full-block factor. Selected artwork and custom names do not change the result.

This table covers block bodies. Inventory stacks and tank contents are added separately when scanning: for example, 1,000 mB of ordinary water in a tank adds 0.4 units. See [vehicle weight and cargo rules](pilot-seat-taxi.md#estimated-vehicle-weight). Source: [VehicleWeight.java](../src/main/java/com/vandorlabs/vehicle/VehicleWeight.java).
