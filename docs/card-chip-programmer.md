# Card / Chip Programmer

Place the programmer with two blocks of width and two blocks of height clear. The console faces the player. All four occupied cells share one inventory. Breaking any occupied cell dismantles the console and releases its three retained items once.

Right-click the actual **Master**, **Input**, or **Output** pad or socket with a suitable held item to insert one item without opening the dialog. Use an empty hand on an occupied pad to remove its item. Master accepts a company Access Card or Master Data Chip; Input and Output accept Access Cards and Data Chips. Other console surfaces open the standard dark dialog, except the Journal display's page controls. Items stay inserted when the dialog closes or the world saves, and their actual models appear in the sockets.

Put the item to program in **Input** and leave **Output** empty. **Program** consumes that input item and moves the programmed result into Output. It retains the Master item. An occupied Output blocks programming. Remove the result or move it back into Input to program it again. Program is disabled while Input is empty.

For example, place a Vandor Master Data Chip in Master and an Access Card in Input. Program produces a Vandor Access Card in Output, replacing any previous company branding on that input card. Already branded items retain their company when no master is inserted. Blank Access Cards and blank Master Data Chips need a company master. An unbranded Journal Chip can be written without one.

To duplicate an existing card or chip's data, put the source in **Input** and another item of the same base kind in **Output**, then click **Copy**. Card copies require two Access Cards; chip copies require two Data Chips. Copy overwrites the existing output item's company, name and full saved data, keeping exactly one item in each slot. Input and Master stay unchanged, and no matching master is needed. The target may already belong to another company. Copy uses the actual saved Input item; pending Journal editor changes are not copied until programmed into an item.

The bottom navigation buttons open **Inventory**, plus **Journal** while Input contains a Data Chip with Type set to Journal, or close the dialog with **Done**. Both pages show the same three retained slots. Inventory shows the player inventory. **Program** and **Copy** sit just above navigation. The **Type** selector applies only to Data Chips; it is disabled for Access Cards. Left-click selects the next type and right-click selects the previous type. Existing company Data Chips are Master Data Chips, and the unbranded item is a Blank Data Chip; their existing item identifiers and company variants remain compatible with readers.

Insert a Journal Chip in **Input** to display its title and contents on the Journal page. Journals have a title of up to 40 characters and eight plain-text pages of up to 512 characters each. The title appears in the chip's item name. Use the page arrows to paginate. Click the text area to type; Enter, Backspace, Delete, Home, End, arrow keys, Select All, copy and paste are supported. The mouse wheel scrolls longer pages. Editing applies only to the input chip's pending journal contents. Program writes those contents and moves the physical chip to Output. Putting a journal in Output never loads it into the editor; only the explicit Copy action overwrites an occupied Output item.

Pending input journal edits save automatically after a short pause and before closing with Done, Escape or the inventory key. The console's large physical screen shows the input Journal draft, or the programmed Journal in Output when no input Journal draft is selected. Click **Previous** or **Next** directly on that screen to read it without opening the dialog. Long entries continue across additional screen views. Paging never edits the chips or their contents, and changing the displayed source or contents resets to the first view. With no Journal present the large screen stays black. The keyboard retains the existing artwork and its original proportions.
