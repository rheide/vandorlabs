# Retired industrial machinery

Aster, Rivet Dynamics, Vektor, Kestrel and Hadron machinery blocks, items, recipes, models and textures have been removed. Their registry IDs are no longer available; there are no remapping aliases.

Canopies, programmable blocks, propulsion and vehicle controls remain available. The import and curation tools exclude all five retired manufacturers. The unused machinery tiles, renderers, packets and configuration paths are removed.
