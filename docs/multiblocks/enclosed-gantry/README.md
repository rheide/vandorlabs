# Enclosed Gantry

Build a **5 wide × 3 deep × 4 high** assembly with **34 Programmable Matter Blocks** and **one Enclosed Gantry Core**. Core blocks are available in Creative, following the existing Universal Constructor system.

## 1. Build the base

Lay out a solid 5 × 3 bottom layer. Put the matching Core in the front-left corner, facing you, and fill every other cell with Programmable Matter Blocks.

![Enclosed Gantry: build the base](stage-1.svg)

## 2. Raise the corner pillars

At each of the four corners, build up to a total height of 4 blocks, including the bottom layer. Leave the interior empty.

![Enclosed Gantry: raise the corner pillars](stage-2.svg)

## 3. Connect the top rim

Connect the four pillar tops with a rectangular rim of Programmable Matter Blocks. Keep the middle of the roof open; do not fill the interior.

![Enclosed Gantry: connect the top rim](stage-3.svg)

## 4. Assemble

Right-click the Core. The frame becomes the complete model, and its occupied cells are reserved. If formation fails, use the reported cell to check the frame and its empty interior.

![Enclosed Gantry: assemble](stage-4.svg)

## Facing and removal

The same frame works along either horizontal axis and with the Core in any bottom corner. The placed facing is preferred when it fits. Sneak-right-click the Core to dismantle; on a machine with a holder, aim away from the holder to dismantle rather than configure it. Mining a reserved part dismantles the frame and removes that cell. Breaking the Core restores the remaining Matter Blocks.

On Forge 1.12.2, the Gantry builds mechanical parts from Programmable Matter
Blocks at 40 RF/tick for 200 ticks. The rail moves forward/backward and its
smaller head moves left/right above a blue scanning beam while building.
Click the completed block in the chamber to collect it. See
[production and port details](../../universal-constructors.md). On NeoForge
1.21.1, see [Enclosed Gantry operation](../../builders-1.21.md#enclosed-gantry-operation)
for the native arm and landing-gear recipes.
The former three-high frame is no longer a valid Gantry recipe.
