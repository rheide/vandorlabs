# Universal Constructors

The Assembly Press, Synthesis Tower, and Enclosed Gantry are decorative multiblock assemblies. Their Core blocks are currently creative-only. They do not process recipes yet.

| Core | Width ? depth ? height |
| --- | --- |
| Assembly Press | 4 ? 3 ? 3 |
| Synthesis Tower | 3 ? 3 ? 5 |
| Enclosed Gantry | 5 ? 3 ? 3 |

Place a Core at the front-left corner of the base when looking in the machine's forward direction. For a north-facing machine this is its minimum X/Z corner. Fill the rest of the base with Programmable Matter Blocks. Build a pillar at each corner up to the height in the table, then connect their tops with a rectangular rim of Matter Blocks. Keep the interior empty. The complete frame assembles automatically; right-click the Core to check it immediately.

Sneak-right-click the Core to dismantle the assembly back into its frame. Breaking the Core also restores the Matter Blocks. The hidden occupied cells prevent other blocks from overlapping the complete model. Each cell records its original frame material so restoration also survives chunk unloading. Rotate placement to turn the whole footprint; the core remains the same corner relative to the machine's front.
